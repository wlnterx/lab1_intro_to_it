Начало
Создать матрицу 3×3
Инициализировать переменные:
maxznach = минимально возможное целое число
minznach = максимально возможное целое число
Ввод данных: прочитать все элементы матрицы с клавиатуры
Обработка каждой строки (цикл по i от 0 до 2):
Установить proizved = 1 (произведение элементов строки)
Для каждого элемента в строке умножить proizved на этот элемент
Если произведение строки больше текущего максимума:
Обновить maxznach и запомнить номер строки maxstr
Если произведение строки меньше текущего минимума:
Обновить minznach и запомнить номер строки minstr
Вывод результата:
Вывести номер строки с максимальным произведением
Вывести значение максимального произведения
Вывести все элементы этой строки
Вывести номер строки с минимальным произведением
Вывести значение минимального произведения
Вывести все элементы этой строки
