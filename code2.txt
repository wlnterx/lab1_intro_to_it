# Словесный алгоритм программы перевода чисел

1. **Начало программы**
   * Подключить библиотеки ввода-вывода и работы со строками
   * Установить русскую локаль для корректного отображения кириллицы

2. **Выбор направления перевода**
   * Вывести на экран меню с двумя вариантами:
     * 1 — перевод из 12-ричной системы в 11-ричную
     * 2 — перевод из 11-ричной системы в 12-ричную
   * Считать выбор пользователя в переменную `vibor`

3. **Определение систем счисления**
   * Если выбран вариант 1:
     * Исходная система (`from_base`) = 12
     * Целевая система (`to_base`) = 11
   * Если выбран вариант 2:
     * Исходная система (`from_base`) = 11
     * Целевая система (`to_base`) = 12

4. **Ввод числа**
   * Вывести подсказку для пользователя:
     * "Введите число в X-ричной системе (цифры 0-9, A=10"
     * Если исходная система 12-ричная, добавить ", B=11"
     * Закрыть скобку и двоеточие
   * Считать введенное число как строку `chislo`

5. **Преобразование в десятичную систему**
   * Создать переменную `n` для десятичного значения, инициализировать 0
   * Для каждого символа `c` в строке `chislo`:
     * Умножить `n` на `from_base` (сдвиг разряда)
     * Если символ `c` — цифра от '0' до '9':
       * Прибавить к `n` значение этой цифры (`c - '0'`)
     * Иначе если символ `c` — 'A' или 'a':
       * Прибавить к `n` значение 10
     * Иначе если символ `c` — 'B' или 'b' И `from_base` равно 12:
       * Прибавить к `n` значение 11
     * Иначе (недопустимый символ):
       * Вывести сообщение об ошибке с указанием неверного символа
       * Завершить программу с кодом 1

6. **Преобразование из десятичной в целевую систему**
   * Создать строку `result` для результата
   * Если `n` равно 0, установить `result` = "0"
   * Иначе инициализировать `result` пустой строкой
   * Пока `n` больше 0:
     * Найти остаток от деления `n` на `to_base` (переменная `d`)
     * Определить символ для остатка:
       * Если `d` < 10: символ = '0' + `d` (цифра)
       * Если `d` == 10: символ = 'A'
       * Иначе: символ = 'B'
     * Добавить полученный символ в начало строки `result`
     * Разделить `n` на `to_base` (целочисленно)

7. **Вывод результата**
   * Вывести сообщение: "Результат в Y-ричной системе: " + `result`

8. **Конец программы**
   * Вернуть 0 (успешное завершение)
